# S1 task cards: draw.io viewer plugin (production)

Source of scope: approved `DESIGN-v5-ru.md` (sha256 `db454dc7…addcb`), section 7 row S1.
This file breaks that scope into executable cards. It is not a new design and adds no gate.

## Fixed technical choices (settled from evidence, not owner decisions)

| Topic | Choice | Reason |
|---|---|---|
| Plugin root | Repository root is the plugin root; `client/`, `server/`, `shared/` only | Paseo 0.15.0 compiler rejects code modules elsewhere |
| Manifest | id `drawio`, `requirements.paseo` `>=0.15.0` | Only verified host; hook names `addHook("agent.open.before")`, `useFileText`, `addFilePanel`, `Markdown`, `addSlashCommand` are typed in the 0.15.0 SDK |
| Viewer build | `js/viewer-static.min.js` from official `draw.war` release v32.6.10 (sha256 `dfa1cfb4…5928`, 8,808,136 B) | Same engine as the CDN build used in S0 (identical through byte 4,934,655) plus embedded stencil libraries, so stencils render with remote loading blocked. One pinned build closes R10 |
| Viewer delivery | Vendored as `server/assets/viewer-static.min.js.txt` (byte-identical, `.txt` so esbuild bundles it as text). Served by RPC `drawio.viewer-asset` as a string with version and sha256; integrity checked on the daemon before serving | Plugin processes have no runtime path to their own directory; binary RPC output fails on web (S0) |
| Client cache | TanStack Query key `["drawio-viewer", version]`, `staleTime`/`gcTime` Infinity: one fetch per client session | R3 |
| Frame isolation | `<iframe sandbox="allow-scripts" srcdoc>`; CSP meta in srcdoc: no network, images/fonts only `data:`/`blob:` | D7 egress; external images are blocked, not fetched |
| Frame budget | Global LRU budget of live frames (file panels pinned, timeline frames evictable); evicted rows show a recoverable "Show diagram" placeholder | Memory bound per S0 review item 3 |
| Tool Server | `@drawio/mcp@1.10.1` exact runtime dependency, locked by `npm-shrinkwrap.json`; launched through `server/launcher/drawio-toolserver.mjs` | No `cwd` field in Paseo stdio MCP config |
| Locating the plugin on the daemon | Read `plugins` from daemon config through the plugin's own `PaseoApi`, pick the directory whose `package.json` name is `paseo-plugin-drawio`, resolve `@drawio/mcp` from it with Node resolution | The server bundle is evaluated without `__dirname` or `import.meta.url` |
| Launcher duties | `chdir(workspace)`, then proxy stdio to the official server; hide and refuse `open_drawio_xml`, `open_drawio_csv`, `open_drawio_mermaid`; add the agent contract as MCP `initialize.instructions` | The `open_*` tools launch a browser on the daemon host at `app.diagrams.net` with the diagram in the URL, which D7 forbids without an explicit user action |
| Tool Server env | `DRAWIO_ICON_SERVICE_URL=off`, `DRAWIO_BASE_URL=http://127.0.0.1:9/`, `ELECTRON_RUN_AS_NODE=1`; the launcher sets `DRAWIO_SHAPE_INDEX_URL` to the shipped `server/assets/shape-search-index.json` | Defence in depth if a blocked tool is ever reached; Electron hosts; shape search without downloads |
| Providers | Inject only for `purpose: "interactive"` and providers in `MCP_PROVIDERS` (`claude`, `codex`, `opencode`: 0.15.0 source declares `supportsMcpServers: true`). Others are skipped so the open never fails | Real-launch confirmation is an acceptance item (R2) |
| MCP server key | `paseo-drawio` | Avoids colliding with a user-configured `drawio` server |
| `/drawio` | Agent-context client slash command; sends the prompt to the current agent with `paseo.agents.ref(id).send`; empty args ask the agent to clarify | D6 |
| Native clients | Honest notice; no rendering | Section 6 open |
| External opening | No open action in S1; diagram links cannot open (no `allow-popups`) | D7 local-open condition is undecided |

## Cards and commit boundaries

All production cards land in one local checkpoint commit (C1). Tests land in a separate
commit (C2) by the test author. Final reviewed commit is made after test integration.

## Test seams (for the separate test author)

Pure, importable without Paseo or DOM:

- `shared/fences.ts`: `splitDrawioFences(text, phase)` (CommonMark fences, including inside block
  quotes and list items) returns ordered segments
  (`text`, `diagram`, `pending`); `toTimelineItems(segments)` returns plugin items with unique ids.
- `shared/diagram.ts`: `classifyDiagramXml(xml)` (`ok` / `empty` / `too-large` / `not-drawio`), `countPages(xml)`.
- `shared/prompt.ts`: `buildDrawioPrompt(args)`; `DRAWIO_AGENT_INSTRUCTIONS`.
- `shared/providers.ts`: `shouldInjectToolServer(request)`.
- `server/toolserver.ts`: `buildToolServerEntry({ execPath, launcherPath, serverEntry, cwd })`.
- `server/plugin-root.ts`: `selectPluginRoot(entries, readPackageName)` with injected probe.
- `server/viewer-asset.ts`: `verifyViewerSource(source, expectedSha)`.
- `server/launcher/drawio-toolserver.mjs` exports `transformClientMessage`, `transformServerMessage`,
  `BLOCKED_TOOLS`; `main()` runs only when executed directly.
- `client/frame-budget.ts`: `FrameBudget` (no DOM): `acquire`, `release`, `touch`, eviction callback.
- `client/web.ts`: `buildFrameHtml(options)` is a pure string builder (CSP, config escaping).

Runtime acceptance (isolated Paseo, headed browser, provider matrix, fixture matrix, egress)
belongs to the test and acceptance workers, not to this card set.
